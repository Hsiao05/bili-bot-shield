# 别看大肥鱼了！

> 一个 Chrome / Edge（Manifest V3）扩展：在**本地**折叠或隐藏 B 站评论区里疑似 DeepSeek 机器人发的评论。
> **不联网、不读 Cookie、不碰账号**，只修改你自己浏览器里看到的页面。

---

## 这是什么

有一类插件（比如 `dsh-bili-scroll`）会用**号主本人的 B 站账号**，每天在别人视频的评论区留一条「@某人 + 推荐语」式的评论。
这些评论来自很多不同的账号，没有统一的 ID，靠拉黑或搜某个关键词都挡不住；但它们的行为特征高度一致：顶层评论、以 `@` 开头、长度适中、是一套推荐话术、不参与讨论。

本扩展不调用 B 站接口，也不做任何网络请求，而是在**你本机的页面里**做三件事：

1. 在页面主世界拦截评论接口的响应，提前认出疑似评论；
2. 用隔离世界里的 DOM 兜底扫描，给漏网的评论节点做标记；
3. 按你的设置把疑似评论**折叠**（变成一行可展开的提示）或**隐藏**（不显示）。

一句话：**它不让机器人消失，只让你的评论区安静一点。**

---

## 安装

要求：Chrome 111+（`world: MAIN` 内容脚本），Edge 同版本 Chromium 也可以。

1. 把整个 `bili-bot-shield/` 文件夹放到本地任意位置；
2. 打开 `chrome://extensions`（Edge 是 `edge://extensions`）；
3. 打开右上角的「开发者模式」；
4. 点「加载已解压的扩展程序」，选择 `bili-bot-shield/` 文件夹；
5. 打开任意 B 站视频页（`https://www.bilibili.com/video/...`），刷新页面即可生效。

扩展图标来自用户提供的图片，已导出为 `icons/icon16.png`、`icon32.png`、`icon48.png`、`icon128.png`。

## 使用

### 扩展面板

点击浏览器工具栏里的扩展图标打开面板，设置会立即同步到已打开的 B 站页面：

- **总开关**：关闭后页面不做任何处理。
- **处理方式**：三选一
  - **折叠**（默认）：命中评论变成一行「🛡 疑似机器人评论，点击展开」，点一下看原文，再点收起；
  - **隐藏**：整条不显示；
  - **仅记录**：只统计、不改变页面，适合先观察一两天再决定。
- **匹配强度**：**保守**（阈值 8）/ **平衡**（默认，阈值 6）/ **激进**（阈值 4）。激进误伤更多，保守漏网更多。
- **自动学习**：同一账号命中（分数达到当前档位阈值）N 次（默认 3，可选 2/3/5/10）后，该 UID 会被记住并直接隐藏（含它的楼中楼）。记错了可以在「已学习账号」里撤销。
- **手动标记模式**：在「处理方式」下方单独开关，**默认关闭**；打开后在每条评论（包括已折叠的折叠条下方）出现「标记机器人 / 这是真人」按钮，**不会把折叠的评论展开**。
- **外观**：跟随设备 / 浅色 / 深色，默认跟随设备；只影响管理面板本身。
- **手动屏蔽账号名**：按名称**包含**匹配、忽略大小写；例如填「肥鱼」会同时命中「大肥鱼」「大肥鱼本鱼」。填「token」也会命中含 token 的昵称。
- **白名单**：被误伤的账号加进来后不再处理。
- **统计**：今日折叠 / 今日隐藏 / 累计命中 / 已学习账号。
- **数据**：导出 JSON、导入 JSON（合并而不是覆盖）、清空数据。导出内容只含设置、已学习账号、名称屏蔽、白名单。

### 页面内

- 命中规则的评论按当前模式被折叠或隐藏，不会删除、不会改变评论本身；
- 标记模式开启后，可以在评论旁手动标记；
- 页面刷新、翻页、重新加载评论后，新出现的评论会重新判定。

## 判定依据

不是「命中一个词就杀」，而是打分：分数 ≥ 当前档位阈值才处理。

| 信号 | 分值 | 说明 |
|---|---|---|
| 顶层评论以 `@昵称` 开头 | +3 | 这类插件的评论必须 @ 号主 |
| 一次 @ 多个账号 | +2 | 机器人一次把「值得看」群发给多人 |
| 含 AI 推荐语（值得 / 推荐 / 这期 / 视频 / 讲得清楚 / 干货 / 看完 …） | +2 | 插件 `duty.md` 里写死的话术 |
| 疑似 AI 人设口吻（主人 / 本鱼 / 本鲸 / 人家 / 喵 / 🐟 / 咕噜 / 甩尾鳍 …） | +2 | DSH 值班轮常带人设 |
| 插件术语密集（原生工具 / 子 agent / 子代理 / 提示词 / 上下文 / token / skill / 截图 / 查元素 / 看动画 / 落地页 …） | +3（≥5 个不同词）/ +2（3–4 个）/ +1（2 个） | 这是这批评论最强的共性：几乎每条都在复述同一套术语 |
| 「把 X 做成 / 改成 / 封成 Y」改造句式 | +2 | 机器人高频：把 skill 改成原生插件…… |
| 评价/推荐口吻（值钱 / 能打 / 稳了 / 够用 / 省 token / 试水 / 装完 …） | +1 | 比「值得」更宽 |
| 账号名含提示词 | +2 | 肥鱼 / 大肥鱼 / 小肥鱼 / 白饭 / 鲸鱼 / 鲸鱼娘 / 鲸鲸 / 小鲸鱼 / 渔喵 / 鱼 / 鲸 / token / deepseek / dsh / 刷b站 / 机器人 等；只靠名字**不会**单独隐藏 |
| 正文长度 20–200 字 | +1 | 插件对评论长度的约束 |
| 无口语 / 互动标点（没有 哈哈、草、笑死、`?!~` 等） | +1 | 机器人话术通常很「干净」 |
| 楼中楼回复 | −3 | 楼中楼里 @ 人是正常社交 |
| 含链接 / 图片 / BV 号 | −2 | 正常评论更常见 |
| 像真人提问（`?`、`？`、以「吗 / 呢」结尾） | −2（连续追问 −5） | 机器人发的是推荐，不是提问 |
| 真人吐槽口吻（不过 / 但是 / 有点 / 卡 / bug / 翻车 …） | −1 | 机器人很少唱反调 |
| 超长评论（>300 字） | −2 | 正常长评居多 |

阈值：**保守 8 / 平衡 6 / 激进 4**，默认**平衡**。同一账号的多次命中会在「自动学习」里累积，达到设定次数后按 UID 隐藏。

> 实测口径（两批真实评论区语料，共 34 条机器人 + 12 条真人）：
> 平衡档 **34/34 命中机器人、12 条真人里 1 条误伤**（那条账号名是大肥鱼、内容也像机器人，存疑）；
> 保守档 32/34、真人 0 误伤；激进档 34/34、真人 4 条误伤。
> 语料放在 `tests/real-corpus.json`，改规则后可以用 `tests/corpus-eval.mjs` 复跑。

## 隐私与边界

- **不联网**：没有任何网络请求，不调用 B 站接口，不读 Cookie、不碰登录态、不碰账号。
- **只改视图**：折叠 / 隐藏发生在本机页面里；不删评论、不举报、不拉黑，也不会让其他用户或手机 App 看到任何变化。
- **数据只在本地**：设置和学习名单存在浏览器的 `chrome.storage.local` 里；卸载扩展即清除。
- **只对当前浏览器生效**：别人打开同一个视频，看到的还是原样。

---

## 已知限制

- **启发式一定有误伤**：正常用户偶尔也会发「@朋友 + 推荐」；所以默认用「折叠」而不是删除，并提供了白名单、标记模式和撤销入口。
- **B 站改版可能失效**：评论区已确认是 **Web Components + Shadow DOM**（`bili-comments` → `bili-comment-thread-renderer` 等自定义元素），不是旧版的 `.reply-item`。如果 B 站改版或自定义元素结构变化，折叠可能不生效；扩展会尽量兼容旧 `.reply-item` 结构，但无法保证长期有效。
- **需要 Chrome 111+**：主世界脚本依赖 `world: MAIN`。
- **不支持 `m.bilibili.com`**：移动版页面结构不同，未适配。
- **只处理已经加载的评论**：扩展不主动请求评论，翻页或展开楼中楼后才出现的评论，会在加载后重新判定。
- **多账号同模板识别有限**：同一视频下多个账号发同样模板时更容易识别，但无法做到 100%。

## 文件结构

```text
bili-bot-shield/
├── manifest.json            # MV3 清单
├── icons/                   # 扩展图标（由用户提供的图片生成）
├── src/
│   ├── rules.js             # 判定库：打分 / 同模板聚类 / 名称匹配（纯函数，浏览器与 Node 共用）

│   ├── content.js           # 隔离世界：DOM 兜底扫描、折叠、计数、自动学习
│   ├── content.css
│   ├── popup.html
│   ├── popup.css
│   └── popup.js             # 工具栏面板逻辑
├── tests/
│   ├── rules.test.mjs       # 判定库单元测试（零依赖，Node 18+）
│   ├── corpus-eval.mjs      # 用真实评论语料评估三档命中率/误伤

│   └── mock.html            # 离线演示页：12 条假评论 + 档位/模式切换
└── README.md
```

## 开发与测试

不用安装任何依赖：

```bash
# 判定库单元测试（零依赖）
node bili-bot-shield/tests/rules.test.mjs

# 用真实评论语料评估三档命中率 / 误伤
node bili-bot-shield/tests/corpus-eval.mjs

# 或者进入目录后
node tests/rules.test.mjs
node tests/corpus-eval.mjs
```

改 `src/rules.js` 里的正则后，先跑 `corpus-eval.mjs` 看平衡档召回有没有掉、误伤有没有涨，再跑单测。

离线演示页：直接用浏览器打开 `tests/mock.html`，它会加载 `src/rules.js` 并给 12 条假评论打分，可以切换强度和处理方式看效果。
如果 `file://` 下浏览器拦截了本地脚本，在项目根目录起一个静态服务器再访问 `/tests/mock.html`，例如：

```bash
npx serve .
# 或
python -m http.server
```

修改判定规则只需改 `src/rules.js`（纯函数、无副作用），测试与演示页会同步生效。`rules.js` 同时挂到 `globalThis.BSH_RULES` 并支持 CommonJS，便于在浏览器和 Node 之间共用。

## 常见问题

**装了没反应 / 看不到任何效果？**（按顺序查，30 秒能定位）

1. 打开 `chrome://extensions`：
   - 「别看大肥鱼了！」这张卡片在不在？有没有被停用？
   - 卡片上有没有红色「错误」按钮？有的话点开，把错误文本发我。
   - 「站点访问权限」是不是「在所有网站上」？如果是「点击时」，请先点一下扩展图标。
2. 点一下扩展图标，看面板顶部那行**页面状态**：
   - **✅ 已注入：本页扫描到 N 条评论** → 脚本在跑；若没折叠，检查处理方式是不是「仅记录」、是不是开着「标记模式」（标记模式不改变折叠状态，但会显示按钮）、强度是不是「保守」。
   - **⚠️ 已注入，但还没扫描到评论** → 评论区还没加载，向下滚到评论区或刷新页面。
   - **❌ 未检测到页面脚本** → 点图标时会自动补注入一次；仍失败的话，刷新页面再点一次，并确认当前是 `www.bilibili.com` 的视频页/动态页。
3. 版本号必须是 **v0.2.0**（面板右上角）。如果还显示旧版本，说明 Chrome 加载的是旧副本——在 `chrome://extensions` 里点「移除」，重新「加载已解压的扩展程序」，**选到直接包含 `manifest.json` 的那一层目录**（不是它的上一层，也不是 zip 文件）。
4. 按 F12 打开 Console，搜索「别看大肥鱼了」，或直接执行：

```js
document.documentElement.dataset.bcsLoaded   // "1" = content script 在跑
document.documentElement.dataset.bcsStage    // 执行到哪一步：init / ping-ready / started / scan-done:N / 错误信息
document.documentElement.dataset.bcsUnits    // 本页扫描到的评论数
document.documentElement.dataset.bcsMain     // "1" = 主世界接口 hook 在跑
```

把这几行结果和面板状态发我，就能判断是「没注入」「没找到评论区」还是「规则没命中」。

**误伤正常评论怎么办？**
把强度切到「保守」；或在标记模式里点「这是真人」加入白名单；或关掉「自动学习」并撤销对应账号。

**想要完全恢复原样？**
面板 → 数据 → 清空数据，或直接停用 / 卸载扩展。

**会修改我的 B 站账号或评论吗？**
不会。扩展只读页面数据并修改本机视图，没有写操作、没有网络请求。
